# 환경과 버전

이 책은 두 환경을 구분한다.

- **대상 환경**: 독자가 공부하고 일하는 곳. 책의 설명, 메뉴 이름, 경로는 이 환경을 기준으로 쓴다.
- **검증 환경**: 이 책을 쓰면서 예제를 실제로 실행해 본 곳. 책의 "검증 환경에서 …" 결과는 모두 여기서 얻는다.
